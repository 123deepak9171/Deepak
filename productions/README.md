# productions/

Har video production ka shared workspace: `productions/<id>/` (layout: `workflow/PROTOCOL.md`).
Agents yahin brief, script, storyboard, fragments, audio cues, QC reports aur exports likhte hain.

Privacy: ye folder git me **ignore** hota hai (repo public hai). Sirf synthetic test productions
(`_tests/`, `deleg-test-*`) bina heavy media ke commit kiye gaye hain — proof ke liye ki agents ne real files banayi.
