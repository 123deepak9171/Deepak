# Assets (permanent folders)

| Folder | Kya daalna hai | Formats |
|---|---|---|
| `raw-videos/` | Phone se shoot ki hui raw videos | mp4, mov, mkv, webm, 3gp |
| `photos/` | Product / site photos, green-screen backgrounds | jpg, png, webp |
| `logos/` | Company logo (`logo.png`, transparent PNG best) | png |
| `music/` | Royalty-free background music (license wali hi) | mp3, wav, m4a |
| `sfx/` | Sound effects (`whoosh.wav` transitions par auto lagta hai) | wav, mp3 |
| `scripts/` | Video script (.txt) ya subtitles (.srt) — captions ke liye | txt, srt |
| `luts/` | Color grading LUT (.cube) — optional | cube |
| `fonts/` | Mukta / Poppins / Noto Sans Devanagari (OFL license) | ttf |

⚠ Repo public hai to yahan upload ki gayi har file public hogi. Private media se pehle repo **Private** karo.
25 MB se badi video ko GitHub **Release** me attach karke uska `https://github.com/...` link job me `src` ki jagah do.
